A BepInEx and Jotunn-based Valheim mod that patches health and damage for bosses and creatures.

Free free to fork. If you want to build this, the instructions at https://valheim-modding.github.io/Jotunn/guides/guide.html are a good starting point. Note that since this is a pure code mod, that the Unity project features inherited from [JotuModStub](https://github.com/Valheim-Modding/JotunnModStub) when forked have been removed.
